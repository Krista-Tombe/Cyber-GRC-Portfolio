# Incident Summary
Between August and October 2026, an AI-assisted code analysis disclosed two critical vulnerabilities, CVE-2026-109618 and CVE-2026-109619, that could allow unauthenticated remote code execution on vulnerable systems. Attackers did not need a login, user account, or any secured level of access to a PHP based website or server. Security patches were released on October 21, 2026, and the Cybersecurity and Infrastructure Security Agency officially logged the PHP2Shell vulnerability to its Known Exploited Vulnerability catalog.

The vulnerabilities raised concerns about internet-facing web servers, PHP-based applications, and third-party products that rely on vulnerable PHP versions. Reports of exploitation emerged on October 26, increasing the urgency of remediation.
